Учебный сайт **«Компьютерные игры в Steam»** на HTML, CSS и JavaScript.
Это отдельный проект по веб-программированию; последующие работы можно хранить в отдельных репозиториях с теми же метками `web-development`, `html`, `css`, `javascript`.

## Как открыть локально

Откройте `index.html` в браузере. Для редактирования откройте всю папку проекта в VS Code.
Установка зависимостей и сборка не нужны.

## Задача №1013

Даны вещественные X и Y. Если X > Y, Z = X × Y; иначе Z = ln(X + Y).
Логарифм вычисляется только при X + Y > 0. Проверяются пустой ввод и конечность чисел/результата.
Перед отправкой результат пересчитывается по текущим данным.

## Формы и учебные данные

Формы отправляются методом POST на `https://httpbin.org/post`, который показывает полученные значения.
Собственной базы данных и входа в аккаунт Steam нет. Для проверки используйте вымышленные контактные данные и учебный код, а не действующие пароли.
Макет паспорта учебный, данные о выдаче и номер вымышлены.

## Как обновлять сайт

1. Сохранить правки в VS Code и проверить их в браузере.
2. В GitHub Desktop проверить список изменений и выполнить **Commit to main**.
3. Нажать **Push origin**.
4. Дождаться успешного выполнения Pages в разделе **Actions** и проверить сайт.

Источник GitHub Pages: ветка `main`, папка `/(root)`.
Личные PDF, резервные копии и рабочие заметки хранятся вне репозитория сайта.
